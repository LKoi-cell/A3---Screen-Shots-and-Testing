# The Red Rose 🌹 — A2, A3 and A4 Website Project

## Project purpose
The Red Rose is an informational website about the beauty, symbolism, and care of red roses. It is designed to be attractive, clear, accessible, and responsive across mobile, tablet, and desktop screens.

## Features
- Semantic HTML5 page structure and section-based navigation
- Introductory content about red roses
- Meaning cards for love, beauty, and appreciation
- Numbered rose-care tips
- Image gallery with captions and alternative text
- Responsive CSS Grid layouts and mobile/tablet breakpoints
- Keyboard-visible focus styling and reduced-motion support
- Local JPEG assets; no JavaScript or external library dependency

## Technologies
- HTML5
- CSS3 (Grid, Flexbox, media queries, CSS custom properties)
- JPEG images
- Git and GitHub / GitHub Pages (for version control and publishing)

- `index.html` — main page
- `css/style.css` — responsive styling
