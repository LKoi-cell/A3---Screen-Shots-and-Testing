## A4 Project Summary (approximately 400 words)

The Red Rose website is an informational website developed to introduce visitors to the beauty, symbolism, and basic care of red roses. Its purpose is to present flower-related information in a simple, attractive, and organised format that is easy to explore. The target audience includes flower lovers, students, gardeners, and people who want to learn why red roses are commonly associated with love, beauty, and appreciation.

The visual design uses a coordinated red, burgundy, white, and pale-pink colour palette inspired by the subject. A large hero section introduces the website and provides a clear link into the content. Content is divided into named sections—About, Meaning, Care Tips, and Gallery—so visitors can find information without reading one long page. Cards separate the three symbolic meanings, an ordered list makes care advice easy to follow, and image captions provide context for the rose photographs. Alternative text is included for informative images, while semantic HTML elements such as `header`, `nav`, `main`, `section`, `figure`, and `footer` help structure the page.

The website is built with HTML5 and CSS3. HTML provides the page structure, text, navigation links, and images. CSS controls typography, colour, spacing, cards, image cropping, and layout. CSS Grid is used for the two-column introduction, meaning cards, and photo gallery. Responsive media queries change these layouts for smaller screens: the navigation can wrap, multi-column content becomes a single column, spacing is reduced, and footer content stacks vertically. Flexible font sizing with `clamp()`, responsive image sizing, visible keyboard-focus indicators, and a reduced-motion preference improve usability across devices and for different users. The project uses local image assets and does not require JavaScript or an external library.

One challenge in responsive development is ensuring that a design which looks balanced on a desktop does not become cramped or overflow on a phone. This was addressed by using flexible grids, wrapping navigation links, relative sizing, and dedicated breakpoints for mobile and tablet-sized layouts. Local image paths were kept inside the project so the gallery can work when the repository is downloaded or published from its root directory.

Completing this project helped develop practical skills in semantic HTML, CSS layout, media queries, accessibility basics, organising project assets, and preparing a website for publication. The final verification process should include checking all navigation anchors and image paths, validating the HTML with the W3C Nu HTML Checker, previewing mobile, tablet, and desktop widths, and checking the live GitHub Pages version. The student should review the code and be ready to explain how the layout and responsive rules work.
